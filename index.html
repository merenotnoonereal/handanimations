Hand Animations

See your hand holding your items in first person, with real animations for every item.

Vanilla first person is a floating item. Hand Animations puts a hand on it and makes every item move like it has weight.

Download on Modrinth Download on CurseForge GitHub

Hand Animations is a 100% client-side Fabric mod that draws your hand holding your item in first person and gives every item its own animations: swings, eating and drinking, bows and crossbows, shields, fishing rods, a draw animation and an inspect key. It is built for Hypixel SkyBlock, and resource packs can give any item its own grip, animations and model. Nothing to install on the server.

A visible hand in first person

Vanilla Minecraft hides your arm as soon as you hold something, so the item just floats. Hand Animations draws a small forearm at the lower right that holds the item, and your off hand gets one too. Swords sit in the fist by the grip, torches stand upright and blocks keep their top facing up.

Animations for every item

  • Swings by item type. Swords slash, backhand and stab in a combo, tools and drills chop, wands thrust.
  • Use animations. Food and potions go to your mouth, your other hand pulls the bowstring, crossbows charge and kick, shields block, fishing rods cast and reel, plus tridents, spears, brushes, placing blocks and pouring buckets.
  • Inspect key. Press Y to turn the held item over and look at it.
  • Draw, sprint, sway and idle fidgets. Items are drawn when you switch to them, the arm moves when you sprint, trails behind your camera and fidgets when you stand still.

Built for Hypixel SkyBlock

SkyBlock items are vanilla items underneath, so most mods animate a drill like a prismarine shard. Hand Animations reads each item's SkyBlock type (sword, drill, wand, fishing rod, bow, axe, hoe, shovel, gauntlet, deployable) and picks the matching animation. Drills shake while you mine, swords and wands flourish when you use an ability, rods cast.

Custom animations with resource packs

Any resource pack can give an item its own grip, swing, use, draw and inspect animation, and its own model in the hand. Add one JSON file per item in assets/<namespace>/handanimations/items/ and match items by Minecraft id, SkyBlock id or name. Hold an item and run /handanimations item to see its ids and which file matches it.

Item size and swing speed with NoForcedPacks

Hand Animations follows the held item size and swing speed from NoForcedPacks. Install both to make your items smaller or bigger and your swing slower or faster, with the hand still holding them.

How to use

  1. Install Fabric Loader and Fabric API for Minecraft 26.2.
  2. Put the Hand Animations .jar in your mods folder and launch.
  3. Hold anything. The hand is already there. Press Y to inspect.
  4. Open the settings with /handanimations, through Mod Menu, or with a key you bind in Options → Controls → Key Binds.

Every part has its own switch: arm with items, off-hand arm, item swings, sprint pose, draw animation, ability animations, drill shake, use animations and idle fidgets. Sliders set the sway, the inspect speed and the arm's position and rotation.

FAQ

How do I see my hand holding items in first person in Minecraft?
Vanilla Minecraft has no option for it: your arm disappears as soon as you hold an item. Install Hand Animations (Fabric, client-side) and a hand holds every item, with swing, use, draw and inspect animations.
Is there a Hold My Items alternative for Minecraft 26.2?
Yes. Hand Animations does the same job, a visible hand holding your items plus an inspect key, on Minecraft 26.2, and is built around Hypixel SkyBlock items.
Does it work on Hypixel SkyBlock?
Yes, it is built for it. It reads each item's SkyBlock type to pick its animation, so swords, drills, wands and rods each move their own way.
Can I make my own item animations?
Yes. A resource pack can give any item its own grip, animations and model with one JSON file per item. The pack format and an example pack are on GitHub.
How do I change the held item size or swing speed?
Install NoForcedPacks. Hand Animations follows its held item size and swing speed settings.
Do I need to install it on the server?
No. Hand Animations is 100% client-side. Only you need it installed.
Is Hand Animations bannable?
It only changes how your own hand looks on your screen and gives no gameplay advantage. Still, check your server's rules: you're responsible for how you use it.
