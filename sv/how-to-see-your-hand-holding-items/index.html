Så ser du din hand hålla föremål i förstapersonsvy

Uppdaterad 2026-10-21 · Minecraft Java 26.2

Vanilla Minecraft har ingen inställning för det. Installera den gratis Fabric-modden Hand Animations så håller en hand varje föremål i förstapersonsvy, med sving-, användnings-, dra fram- och granskningsanimationer. Tryck på Y för att granska föremålet du håller.

Ladda ner Hand Animations på Modrinth Ladda ner på CurseForge

I vanillas förstapersonsvy ser du bara din arm när handen är tom. Så fort du håller ett svärd, en hacka eller ett block försvinner armen och föremålet svävar vid skärmkanten. Hand Animations ritar tillbaka handen, med föremålet i, och animerar det.

Steg

  1. Installera Fabric Loader för Minecraft Java 26.2 och lägg Fabric API i din mods-mapp.
  2. Ladda ner Hand Animations från Modrinth och lägg .jar-filen i samma mods-mapp.
  3. Starta Minecraft med Fabric-profilen och gå in i valfri värld eller server.
  4. Håll ett föremål. Nu håller en hand det nere till höger, och din andra hand får också en.
  5. Slå, ät, spänn en båge eller tryck på Y för att granska föremålet. Varje handling har sin egen animation.

Inget att ställa in. Dina inställningar sparas mellan omstarter.

Ändra utseendet

Skriv /handanimations eller öppna inställningarna via Mod Menu. Du kan dölja andra handens arm, stänga av vilken animationsgrupp som helst, ändra gungningen och granskningshastigheten och flytta eller vrida armen med reglage. För att göra föremålet mindre eller större, installera NoForcedPacks: Hand Animations följer dess föremålsstorlek och svinghastighet.

Också i samma mod

Hand Animations är gjord för Hypixel SkyBlock och väljer varje föremåls animation efter dess SkyBlock-typ. Resurspaket kan ge vilket föremål som helst egna animationer och en egen modell.

Vanliga frågor

Kan jag se min hand hålla föremål utan mod?
Nej. Minecraft Java visar bara din arm när handen är tom. Du behöver en klientmod som Hand Animations för att rita handen som håller föremålet.
Ser andra spelare handanimationerna?
Nej. Hand Animations ändrar bara din egen förstapersonsvy. Andra spelare ser dig som vanligt, och inget ändras på servern.
Ändrar det min attackhastighet eller räckvidd?
Nej. Det ändrar bara animationer på din skärm. Attacker, brytning och allt servern tar emot förblir detsamma.
