一人称視点でアイテムを持つ手を表示する方法

更新日 2026-10-21 · Minecraft Java 26.2

バニラの Minecraft にはその設定がありません。無料の Fabric MOD Hand Animations を入れると、一人称視点で手がすべてのアイテムを持ち、スイング、使用、持ち替え、眺めるアニメーションが付きます。Y を押すと手に持ったアイテムを眺められます。

Hand Animations を Modrinth でダウンロード CurseForge でダウンロード

バニラの一人称視点では、手が空のときしか腕は見えません。剣やツルハシ、ブロックを持った瞬間に腕は消え、アイテムが画面の端に浮かびます。Hand Animations はアイテムを握った手を描き直し、動かします。

手順

  1. Minecraft Java 26.2 用の Fabric Loader を導入し、Fabric API を mods フォルダに入れます。
  2. Modrinth から Hand Animations をダウンロードし、.jar を同じ mods フォルダに入れます。
  3. Fabric のプロファイルで Minecraft を起動し、好きなワールドかサーバーに入ります。
  4. アイテムを持ちます。右下で手がそれを握り、オフハンドにも手が付きます。
  5. 振る、食べる、弓を引く、または Y でアイテムを眺める。どの動作にも専用のアニメーションがあります。

設定は不要です。設定は再起動後も保存されます。

見た目を変える

/handanimations と入力するか、Mod Menu から設定を開きます。オフハンドの腕を隠す、どのアニメーションのグループもオフにする、揺れと眺める速さを変える、スライダーで腕を動かしたり回したりできます。アイテムを小さくしたり大きくしたりするには NoForcedPacks を入れてください。Hand Animations はその手持ちアイテムサイズとスイング速度に従います。

同じ MOD のその他の機能

Hand Animations は Hypixel SkyBlock 向けに作られており、各アイテムのアニメーションを SkyBlock タイプで選びます。リソースパックで、どのアイテムにも専用のアニメーションとモデルを付けられます。

よくある質問

MOD なしでアイテムを持つ手を表示できる?
できません。Minecraft Java は手が空のときしか腕を表示しません。アイテムを持つ手を描くには、Hand Animations のようなクライアント側の MOD が必要です。
他のプレイヤーにも手のアニメーションは見える?
見えません。Hand Animations が変えるのはあなた自身の一人称視点だけです。他のプレイヤーからはいつも通りに見え、サーバー上では何も変わりません。
攻撃速度やリーチは変わる?
変わりません。変わるのは画面上のアニメーションだけです。攻撃、採掘、サーバーが受け取る内容はすべて同じです。
