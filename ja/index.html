Hand Animations

一人称視点でアイテムを持つ自分の手が見える。すべてのアイテムに本物のアニメーション。

バニラの一人称視点では、アイテムが宙に浮いているだけ。Hand Animations はそこに手を加え、すべてのアイテムを重みがあるかのように動かします。

Hand Animations は、一人称視点でアイテムを持つあなたの手を描き、すべてのアイテムに専用のアニメーションを付ける完全クライアント側の Fabric MOD です。スイング、飲食、弓とクロスボウ、盾、釣り竿、持ち替えアニメーション、そしてアイテムを眺めるキー。Hypixel SkyBlock 向けに作られており、リソースパックでどのアイテムにも専用の持ち方、アニメーション、モデルを付けられます。サーバー側に入れるものはありません。

一人称視点で見える手

バニラの Minecraft は何かを持った瞬間に腕を隠し、アイテムはただ浮いているだけになります。Hand Animations は右下にアイテムを握る小さな前腕を描き、オフハンドにも同じように付けます。剣は柄を握り、松明はまっすぐ立ち、ブロックは上面が上を向きます。

すべてのアイテムにアニメーション

  • アイテムの種類ごとのスイング。剣は斬り、返し斬り、突きのコンボ、ツールとドリルは振り下ろし、杖は突き出します。
  • 使用アニメーション。食べ物やポーションは口元へ、もう片方の手が弓の弦を引き、クロスボウは装填して反動し、盾は構え、釣り竿は投げて巻き取ります。トライデント、槍、ブラシ、ブロックの設置、バケツを注ぐ動きもあります。
  • 眺めるキー。Y を押すと手に持ったアイテムを回して眺められます。
  • 持ち替え、ダッシュ、揺れ、待機中の仕草。アイテムを切り替えると取り出す動きがあり、ダッシュ中は腕が動き、カメラに少し遅れてついてきて、立ち止まると小さな仕草をします。

Hypixel SkyBlock 向け

SkyBlock のアイテムは中身がバニラのアイテムなので、多くの MOD はドリルをプリズマリンの欠片のように動かしてしまいます。Hand Animations は各アイテムの SkyBlock タイプ (剣、ドリル、杖、釣り竿、弓、斧、クワ、シャベル、ガントレット、デプロイアブル) を読み取り、合ったアニメーションを選びます。ドリルは採掘中に振動し、剣と杖はアビリティ使用時に振り回し、釣り竿は投げます。すべてのアニメーションはリソースパックでカスタマイズでき、アイテムごとに動きを選べます。

リソースパックで独自アニメーション

どのリソースパックでも、アイテムに専用の持ち方、スイング、使用、持ち替え、眺めるアニメーション、そして手に持ったときのモデルを付けられます。assets/<namespace>/handanimations/items/ にアイテムごとに JSON ファイルを置き、Minecraft の ID、SkyBlock の ID、または名前でアイテムを指定します。アイテムを持って /handanimations item を実行すると、その ID と一致するファイルが表示されます。

NoForcedPacks でアイテムサイズとスイング速度

Hand Animations は NoForcedPacks の手持ちアイテムサイズとスイング速度に従います。両方を入れると、手で持ったままアイテムを小さくも大きくもでき、スイングを遅くも速くもできます。

使い方

  1. Minecraft 26.2 用の Fabric Loader と Fabric API を導入します。
  2. Hand Animations の .jar を mods フォルダに入れて起動します。
  3. 何かを持つだけ。手はもうそこにあります。Y で眺められます。
  4. 設定は /handanimations、Mod Menu、または 設定 → 操作設定 → キー割り当て で割り当てたキーで開けます。

各部分に個別のスイッチがあります: アイテムを持つ腕、オフハンドの腕、アイテムのスイング、ダッシュ時のポーズ、持ち替えアニメーション、アビリティのアニメーション、ドリルの振動、使用アニメーション、待機中の仕草。スライダーで揺れ、眺める速さ、腕の位置と回転を調整できます。

よくある質問

Minecraft で一人称視点のままアイテムを持つ手を表示するには?
バニラの Minecraft にはその設定がなく、アイテムを持つと腕が消えます。Hand Animations (Fabric、クライアント側) を入れると、手がすべてのアイテムを持ち、スイング、使用、持ち替え、眺めるアニメーションが付きます。
Minecraft 26.2 で使える Hold My Items の代わりはある?
あります。Hand Animations は同じこと、つまりアイテムを持つ見える手と眺めるキーを Minecraft 26.2 で実現し、Hypixel SkyBlock のアイテムを中心に作られています。
Hypixel SkyBlock で使える?
はい、そのために作られています。各アイテムの SkyBlock タイプを読んでアニメーションを選ぶので、剣、ドリル、杖、釣り竿がそれぞれ違う動きをします。
自分でアイテムアニメーションを作れる?
はい。リソースパックで、アイテムごとに JSON ファイルを 1 つ置けば、どのアイテムにも専用の持ち方、アニメーション、モデルを付けられます。形式とサンプルパックは GitHub にあります。
手に持ったアイテムのサイズやスイング速度を変えるには?
NoForcedPacks を入れてください。Hand Animations はその手持ちアイテムサイズとスイング速度に従います。
サーバーにも入れる必要がある?
いいえ。Hand Animations は完全にクライアント側です。あなただけが入れれば使えます。
Hand Animations で BAN される?
自分の画面に映る自分の手の見た目を変えるだけで、ゲーム上の有利はありません。それでもサーバーのルールは確認してください。使い方の責任はあなたにあります。

Hold My Items から乗り換え?

Hold My Items は一人称視点で手を見えるようにしましたが、最新版は Minecraft 1.21.11 向けです。Hand Animations は同じアイデアを Minecraft 26.2 に持ち込み、Hypixel SkyBlock のアニメーション、リソースパックによるアイテムごとのアニメーション、NoForcedPacks のアイテムサイズとスイング速度を加えています。
