So siehst du deine Hand, die Items in der Ego-Perspektive hält

Aktualisiert 2026-10-21 · Minecraft Java 26.2

Vanilla-Minecraft hat dafür keine Einstellung. Installiere den kostenlosen Fabric-Mod Hand Animations, dann hält eine Hand jedes Item in der Ego-Perspektive, mit Schwung-, Benutzungs-, Zieh- und Ansehen-Animationen. Drück Y, um das gehaltene Item anzusehen.

In Vanilla siehst du deinen Arm in der Ego-Perspektive nur mit leerer Hand. Sobald du ein Schwert, eine Spitzhacke oder einen Block hältst, verschwindet der Arm und das Item schwebt am Bildrand. Hand Animations zeichnet die Hand wieder ein, mit dem Item darin, und animiert es.

Schritte

  1. Installiere Fabric Loader für Minecraft Java 26.2 und leg Fabric API in deinen mods-Ordner.
  2. Lade Hand Animations von Modrinth herunter und leg die .jar in denselben mods-Ordner.
  3. Starte Minecraft mit dem Fabric-Profil und betritt eine beliebige Welt oder einen Server.
  4. Halte ein Item. Jetzt hält es eine Hand unten rechts, und deine Zweithand bekommt auch eine.
  5. Schlag zu, iss, spann einen Bogen oder drück Y, um das Item anzusehen. Jede Aktion hat ihre eigene Animation.

Nichts einzurichten. Deine Einstellungen bleiben über Neustarts hinweg gespeichert.

Das Aussehen ändern

Gib /handanimations ein oder öffne die Einstellungen über Mod Menu. Du kannst den Arm der Zweithand ausblenden, jede Animationsgruppe abschalten, Schwanken und Ansehtempo ändern und den Arm mit Reglern verschieben oder drehen. Für kleinere oder größere Items installiere NoForcedPacks: Hand Animations übernimmt dessen Itemgröße und Schwunggeschwindigkeit.

Außerdem im selben Mod

Hand Animations ist für Hypixel SkyBlock gebaut und wählt die Animation jedes Items nach seiner SkyBlock-Art. Ressourcenpakete können jedem Item eigene Animationen und ein eigenes Modell geben.

FAQ

Kann ich meine Hand mit Items ohne Mod sehen?
Nein. Minecraft Java zeigt deinen Arm nur mit leerer Hand. Damit die Hand das Item hält, brauchst du einen clientseitigen Mod wie Hand Animations.
Sehen andere Spieler die Hand-Animationen?
Nein. Hand Animations ändert nur deine eigene Ego-Perspektive. Andere Spieler sehen dich wie immer, und auf dem Server ändert sich nichts.
Ändert es meine Angriffsgeschwindigkeit oder Reichweite?
Nein. Es ändert nur Animationen auf deinem Bildschirm. Angriffe, Abbauen und alles, was der Server erhält, bleiben gleich.
