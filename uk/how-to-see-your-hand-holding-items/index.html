Як бачити свою руку з предметами від першої особи

Оновлено 2026-10-21 · Minecraft Java 26.2

У ванільному Minecraft такого налаштування немає. Установіть безкоштовний мод для Fabric Hand Animations, і рука триматиме кожен предмет від першої особи, з анімаціями замаху, використання, діставання та огляду. Натисніть Y, щоб оглянути предмет у руці.

Завантажити Hand Animations з Modrinth Завантажити з CurseForge

У ванільному вигляді від першої особи руку видно, лише коли вона порожня. Щойно ви берете меч, кайло чи блок, рука зникає, а предмет висить збоку екрана. Hand Animations знову малює руку з предметом і анімує його.

Кроки

  1. Установіть Fabric Loader для Minecraft Java 26.2 і покладіть Fabric API у теку mods.
  2. Завантажте Hand Animations з Modrinth і покладіть .jar у ту саму теку mods.
  3. Запустіть Minecraft із профілем Fabric і зайдіть у будь-який світ або на будь-який сервер.
  4. Візьміть предмет. Тепер його тримає рука праворуч унизу, і друга рука теж отримує свою.
  5. Ударте, поїжте, натягніть лук або натисніть Y, щоб оглянути предмет. Кожна дія має власну анімацію.

Нічого налаштовувати не треба. Налаштування зберігаються між перезапусками.

Змініть вигляд

Введіть /handanimations або відкрийте налаштування через Mod Menu. Можна сховати другу руку, вимкнути будь-яку групу анімацій, змінити похитування і швидкість огляду, а повзунками зсунути чи повернути руку. Щоб зробити предмет меншим чи більшим, установіть NoForcedPacks: Hand Animations бере з нього розмір предмета в руці та швидкість замаху.

Також у цьому ж моді

Hand Animations створений для Hypixel SkyBlock і обирає анімацію кожного предмета за його типом SkyBlock. Набори ресурсів можуть дати будь-якому предмету власні анімації та модель.

Часті запитання

Чи можна бачити руку з предметами без мода?
Ні. Minecraft Java показує руку, лише коли вона порожня. Щоб рука тримала предмет, потрібен клієнтський мод на кшталт Hand Animations.
Чи бачать інші гравці анімації руки?
Ні. Hand Animations змінює лише ваш власний вигляд від першої особи. Інші гравці бачать вас як завжди, а на сервері нічого не змінюється.
Чи змінює він швидкість атаки або дальність?
Ні. Він змінює лише анімації на вашому екрані. Атаки, копання і все, що отримує сервер, залишаються такими самими.
