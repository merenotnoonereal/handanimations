1인칭 시점에서 아이템을 든 손을 보는 방법

업데이트 2026-10-21 · Minecraft Java 26.2

바닐라 마인크래프트에는 그런 설정이 없습니다. 무료 Fabric 모드 Hand Animations를 설치하면 1인칭 시점에서 손이 모든 아이템을 들고, 휘두르기, 사용, 꺼내기, 살펴보기 애니메이션이 붙습니다. Y를 눌러 든 아이템을 살펴보세요.

Modrinth에서 Hand Animations 다운로드 CurseForge에서 다운로드

바닐라 1인칭 시점에서는 손이 비어 있을 때만 팔이 보입니다. 검, 곡괭이, 블록을 드는 순간 팔은 사라지고 아이템이 화면 가장자리에 떠 있습니다. Hand Animations는 아이템을 쥔 손을 다시 그리고 움직이게 합니다.

단계

  1. 마인크래프트 Java 26.2용 Fabric Loader를 설치하고 Fabric API를 mods 폴더에 넣습니다.
  2. Modrinth에서 Hand Animations를 다운로드하고 .jar를 같은 mods 폴더에 넣습니다.
  3. Fabric 프로필로 마인크래프트를 실행하고 아무 월드나 서버에 들어갑니다.
  4. 아이템을 들어 보세요. 이제 오른쪽 아래에서 손이 그것을 쥐고, 보조 손에도 손이 생깁니다.
  5. 휘두르기, 먹기, 활 당기기, 또는 Y로 아이템 살펴보기. 모든 동작에 고유한 애니메이션이 있습니다.

설정할 것이 없습니다. 설정은 재시작 후에도 저장됩니다.

모양 바꾸기

/handanimations를 입력하거나 Mod Menu에서 설정을 여세요. 보조 손 팔을 숨기고, 원하는 애니메이션 그룹을 끄고, 흔들림과 살펴보기 속도를 바꾸고, 슬라이더로 팔을 옮기거나 돌릴 수 있습니다. 아이템을 작게 또는 크게 하려면 NoForcedPacks를 설치하세요. Hand Animations는 그 손에 든 아이템 크기와 휘두르기 속도를 따릅니다.

같은 모드의 다른 기능

Hand Animations는 Hypixel SkyBlock용으로 만들어졌고, 각 아이템의 애니메이션을 SkyBlock 종류로 고릅니다. 리소스 팩으로 어떤 아이템에든 고유한 애니메이션과 모델을 줄 수 있습니다.

자주 묻는 질문

모드 없이 아이템을 든 손을 볼 수 있나요?
아니요. 마인크래프트 Java는 손이 비어 있을 때만 팔을 보여 줍니다. 아이템을 든 손을 그리려면 Hand Animations 같은 클라이언트 모드가 필요합니다.
다른 플레이어도 손 애니메이션을 보나요?
아니요. Hand Animations는 내 1인칭 시점만 바꿉니다. 다른 플레이어에게는 평소처럼 보이고, 서버에서는 아무것도 바뀌지 않습니다.
공격 속도나 사거리가 바뀌나요?
아니요. 화면의 애니메이션만 바뀝니다. 공격, 채굴, 서버가 받는 모든 것은 그대로입니다.
