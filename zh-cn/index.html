Hand Animations

在第一人称下看到你的手握着物品，每件物品都有真实的动画。

原版的第一人称只是一件漂浮的物品。Hand Animations 给它加上一只手，让每件物品都像有重量一样动起来。

在 Modrinth 下载 在 CurseForge 下载 GitHub

Hand Animations 是一个纯客户端的 Fabric 模组，在第一人称下绘制你握着物品的手，并给每件物品专属动画：挥动、吃喝、弓与弩、盾牌、钓鱼竿、拔出动画，以及查看物品的按键。它专为 Hypixel SkyBlock 打造，而资源包可以给任何物品设置专属的握法、动画和模型。服务器上无需安装任何东西。

第一人称下可见的手

原版 Minecraft 一旦你拿起东西就会隐藏手臂，物品只是漂浮着。Hand Animations 在右下角画出一只握着物品的小前臂，副手也会有一只。剑握在剑柄处，火把竖直立着，方块保持顶面朝上。

每件物品都有动画

  • 按物品类型挥动。剑会劈砍、反手斩和突刺组成连招，工具和钻头向下劈，法杖向前刺。
  • 使用动画。食物和药水送到嘴边，另一只手拉弓弦，弩装填并后坐，盾牌格挡，钓鱼竿抛出并收回，还有三叉戟、矛、刷子、放置方块和倒桶。
  • 查看按键。按 Y 翻转手中的物品仔细查看。
  • 拔出、疾跑、晃动和待机小动作。切换物品时有拔出动作，疾跑时手臂摆动，略微延迟地跟随视角，站着不动时会做些小动作。

专为 Hypixel SkyBlock 打造

SkyBlock 物品本质上是原版物品，所以大多数模组会把钻头当成海晶碎片来做动画。Hand Animations 会读取每件物品的 SkyBlock 类型（剑、钻头、法杖、钓鱼竿、弓、斧、锄、锹、拳套、可部署物），并选择对应的动画。钻头挖掘时会抖动，剑和法杖使用技能时会挥舞一圈，钓鱼竿会抛竿。每个动画都可以用资源包自定义：为任意物品选择它的动作方式。

用资源包自定义动画

任何资源包都可以给物品设置专属的握法、挥动、使用、拔出和查看动画，以及手中显示的模型。在 assets/<namespace>/handanimations/items/ 中为每件物品放一个 JSON 文件，按 Minecraft ID、SkyBlock ID 或名称匹配物品。手持物品并输入 /handanimations item，即可查看它的 ID 和匹配的文件。

搭配 NoForcedPacks 调整物品大小和挥动速度

Hand Animations 会沿用 NoForcedPacks 的手持物品大小和挥动速度。两个一起安装，就能在手仍然握着物品的情况下把物品变小或变大、把挥动变慢或变快。

使用方法

  1. 为 Minecraft 26.2 安装 Fabric Loader 和 Fabric API。
  2. 把 Hand Animations 的 .jar 放进 mods 文件夹并启动游戏。
  3. 随便拿起什么。手已经在那里了。按 Y 查看。
  4. 用 /handanimations、Mod Menu，或在 选项 → 控制 → 按键绑定 中设置的按键打开设置。

每个部分都有独立开关：手持物品时显示手臂、副手手臂、物品挥动、疾跑姿势、拔出动画、技能动画、钻头抖动、使用动画和待机小动作。滑块可以调整晃动、查看速度，以及手臂的位置和旋转。

常见问题

如何在 Minecraft 第一人称下看到自己的手握着物品？
原版 Minecraft 没有这个选项：一拿起物品手臂就会消失。安装 Hand Animations（Fabric，客户端），手就会握住每件物品，并带有挥动、使用、拔出和查看动画。
Minecraft 26.2 有 Hold My Items 的替代品吗？
有。Hand Animations 在 Minecraft 26.2 上做同样的事：可见的手握着你的物品，外加查看按键，并且围绕 Hypixel SkyBlock 物品设计。
能在 Hypixel SkyBlock 上用吗？
能，它就是为此打造的。它读取每件物品的 SkyBlock 类型来选择动画，所以剑、钻头、法杖和钓鱼竿各有各的动作。
我能自己做物品动画吗？
能。资源包中每件物品放一个 JSON 文件，就能给任何物品设置专属的握法、动画和模型。格式说明和示例资源包都在 GitHub 上。
如何更改手持物品的大小或挥动速度？
安装 NoForcedPacks。Hand Animations 会沿用它的手持物品大小和挥动速度。
需要在服务器上安装吗？
不需要。Hand Animations 是纯客户端模组，只需你自己安装。
使用 Hand Animations 会被封号吗？
它只改变你自己屏幕上手的外观，不提供任何游戏优势。但还是请查看服务器规则：如何使用由你自己负责。

从 Hold My Items 迁移过来？

Hold My Items 让手在第一人称下可见，但它的最新版本只支持 Minecraft 1.21.11。Hand Animations 把同样的想法带到 Minecraft 26.2，并加入了 Hypixel SkyBlock 动画、资源包定义的单物品动画，以及 NoForcedPacks 的物品大小和挥动速度。
