如何在第一人称下看到手握物品

更新于 2026-10-21 · Minecraft Java 26.2

原版 Minecraft 没有这个设置。安装免费的 Fabric 模组 Hand Animations，第一人称下就会有一只手握着每件物品，并带有挥动、使用、拔出和查看动画。按 Y 查看手中的物品。

原版第一人称下，只有空手时才能看到手臂。一旦拿起剑、镐或方块，手臂就消失了，物品漂浮在屏幕一侧。Hand Animations 把握着物品的手重新画出来，并让它动起来。

步骤

  1. 为 Minecraft Java 26.2 安装 Fabric Loader，并把 Fabric API 放进 mods 文件夹。
  2. 从 Modrinth 下载 Hand Animations，把 .jar 放进同一个 mods 文件夹。
  3. 用 Fabric 配置启动 Minecraft，进入任意世界或服务器。
  4. 拿起一件物品。现在右下角有一只手握着它，副手也会有一只。
  5. 挥动、进食、拉弓，或按 Y 查看物品。每个动作都有自己的动画。

无需任何设置。设置在重启后依然保存。

调整外观

输入 /handanimations 或通过 Mod Menu 打开设置。你可以隐藏副手手臂、关闭任意一组动画、调整晃动和查看速度，并用滑块移动或旋转手臂。想让物品变小或变大，请安装 NoForcedPacks：Hand Animations 会沿用它的手持物品大小和挥动速度。

同一模组的其他功能

Hand Animations 专为 Hypixel SkyBlock 打造，会按 SkyBlock 类型为每件物品选择动画。资源包可以给任何物品设置专属动画和模型。

常见问题

不装模组能看到手握物品吗？
不能。Minecraft Java 只有空手时才显示手臂。要画出握着物品的手，需要像 Hand Animations 这样的客户端模组。
其他玩家能看到手部动画吗？
看不到。Hand Animations 只改变你自己的第一人称视角。其他玩家看到的你和平常一样，服务器上也没有任何变化。
会改变攻击速度或攻击距离吗？
不会。它只改变你屏幕上的动画。攻击、挖掘以及服务器收到的一切都保持不变。
