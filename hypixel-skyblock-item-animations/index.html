Hypixel SkyBlock item animations

Updated 2026-10-21 · Minecraft Java 26.2

Install Hand Animations (Fabric, client-side). It reads the type line at the bottom of every SkyBlock item's lore, like LEGENDARY DUNGEON SWORD or MYTHIC DRILL, and gives the item the matching first-person animation, with a hand holding it.

Almost every SkyBlock item is a vanilla item underneath: a Hyperion is an iron sword, many drills are prismarine shards, wands are sticks or rods. Vanilla and most animation mods only see that base item, so a drill swings like a shard. Hand Animations reads the SkyBlock type instead, including recombobulated and dungeon items.

Every item also gets the draw animation when you switch to it and the inspect animation on Y. The drill shake and ability animations each have their own switch in the settings (/handanimations).

Give one item its own animation

Want your Hyperion to swing differently from every other sword? A resource pack can match an item by its SkyBlock id, for example "skyblock_id": "HYPERION", and give it its own grip, swing, ability animation and even its own model in the hand. See custom item animations with a resource pack.

Smaller items, slower swings

If you use NoForcedPacks to turn off the SkyBlock texture pack or shrink your held items, Hand Animations follows its item size and swing speed, so the hand keeps holding the item at any size.

FAQ

Is Hand Animations allowed on Hypixel?
It only changes how your own hand looks on your screen and gives no gameplay advantage. Still, check Hypixel's rules: you're responsible for how you use it.
Does it work with SkyBlock texture packs?
Yes. It animates whatever model the item has, from the server pack, your own packs or vanilla.
Which SkyBlock items get a special animation?
Swords, wands and deployables, drills, tools and gauntlets, fishing rods and bows, read from the type line in the item's lore. Other items use the default hold and swing.
