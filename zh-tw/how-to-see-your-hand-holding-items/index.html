如何在第一人稱下看到手握物品

更新於 2026-10-21 · Minecraft Java 26.2

原版 Minecraft 沒有這個設定。安裝免費的 Fabric 模組 Hand Animations，第一人稱下就會有一隻手握著每件物品，並帶有揮動、使用、拔出和檢視動畫。按 Y 檢視手中的物品。

在 Modrinth 下載 Hand Animations 在 CurseForge 下載

原版第一人稱下，只有空手時才看得到手臂。一旦拿起劍、鎬或方塊，手臂就消失了，物品漂浮在螢幕一側。Hand Animations 把握著物品的手重新畫出來，並讓它動起來。

步驟

  1. 為 Minecraft Java 26.2 安裝 Fabric Loader，並把 Fabric API 放進 mods 資料夾。
  2. 從 Modrinth 下載 Hand Animations，把 .jar 放進同一個 mods 資料夾。
  3. 用 Fabric 設定檔啟動 Minecraft，進入任意世界或伺服器。
  4. 拿起一件物品。現在右下角有一隻手握著它，副手也會有一隻。
  5. 揮動、進食、拉弓，或按 Y 檢視物品。每個動作都有自己的動畫。

不需要任何設定。設定在重新啟動後依然保存。

調整外觀

輸入 /handanimations 或透過 Mod Menu 開啟設定。你可以隱藏副手手臂、關閉任意一組動畫、調整晃動和檢視速度，並用滑桿移動或旋轉手臂。想讓物品變小或變大，請安裝 NoForcedPacks：Hand Animations 會沿用它的手持物品大小和揮動速度。

同一模組的其他功能

Hand Animations 專為 Hypixel SkyBlock 打造，會依 SkyBlock 類型為每件物品選擇動畫。資源包可以為任何物品設定專屬動畫和模型。

常見問題

不裝模組能看到手握物品嗎？
不能。Minecraft Java 只有空手時才顯示手臂。要畫出握著物品的手，需要像 Hand Animations 這樣的客戶端模組。
其他玩家看得到手部動畫嗎？
看不到。Hand Animations 只改變你自己的第一人稱視角。其他玩家看到的你和平常一樣，伺服器上也沒有任何變化。
會改變攻擊速度或攻擊距離嗎？
不會。它只改變你螢幕上的動畫。攻擊、挖掘以及伺服器收到的一切都保持不變。
