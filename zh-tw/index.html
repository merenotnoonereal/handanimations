Hand Animations

在第一人稱下看到你的手握著物品，每件物品都有真實的動畫。

原版的第一人稱只是一件漂浮的物品。Hand Animations 為它加上一隻手，讓每件物品都像有重量一樣動起來。

在 Modrinth 下載 在 CurseForge 下載 GitHub

Hand Animations 是一個純客戶端的 Fabric 模組，在第一人稱下繪製你握著物品的手，並給每件物品專屬動畫：揮動、吃喝、弓與弩、盾牌、釣竿、拔出動畫，以及檢視物品的按鍵。它專為 Hypixel SkyBlock 打造，而資源包可以為任何物品設定專屬的握法、動畫和模型。伺服器上不需要安裝任何東西。

第一人稱下看得到的手

原版 Minecraft 一拿起東西就會隱藏手臂，物品只是漂浮著。Hand Animations 在右下角畫出一隻握著物品的小前臂，副手也會有一隻。劍握在劍柄處，火把直立，方塊保持頂面朝上。

每件物品都有動畫

  • 依物品類型揮動。劍會劈砍、反手斬和突刺組成連招，工具和鑽頭向下劈，法杖向前刺。
  • 使用動畫。食物和藥水送到嘴邊，另一隻手拉弓弦，弩裝填並後座，盾牌格擋，釣竿拋出並收回，還有三叉戟、矛、刷子、放置方塊和倒桶。
  • 檢視按鍵。按 Y 翻轉手中的物品仔細檢視。
  • 拔出、衝刺、晃動和待機小動作。切換物品時有拔出動作，衝刺時手臂擺動，略微延遲地跟隨視角，站著不動時會做些小動作。

專為 Hypixel SkyBlock 打造

SkyBlock 物品本質上是原版物品，所以大多數模組會把鑽頭當成海磷碎片來做動畫。Hand Animations 會讀取每件物品的 SkyBlock 類型（劍、鑽頭、法杖、釣竿、弓、斧、鋤、鏟、拳套、可部署物），並選擇對應的動畫。鑽頭挖掘時會抖動，劍和法杖使用技能時會揮舞一圈，釣竿會拋竿。每個動畫都能用資源包自訂：為任何物品選擇它的動作方式。

用資源包自訂動畫

任何資源包都可以為物品設定專屬的握法、揮動、使用、拔出和檢視動畫，以及手中顯示的模型。在 assets/<namespace>/handanimations/items/ 中為每件物品放一個 JSON 檔案，依 Minecraft ID、SkyBlock ID 或名稱比對物品。手持物品並輸入 /handanimations item，即可查看它的 ID 和對應的檔案。

搭配 NoForcedPacks 調整物品大小和揮動速度

Hand Animations 會沿用 NoForcedPacks 的手持物品大小和揮動速度。兩個一起安裝，就能在手仍握著物品的情況下把物品變小或變大、把揮動變慢或變快。

使用方式

  1. 為 Minecraft 26.2 安裝 Fabric Loader 和 Fabric API。
  2. 把 Hand Animations 的 .jar 放進 mods 資料夾並啟動遊戲。
  3. 隨便拿起什麼。手已經在那裡了。按 Y 檢視。
  4. 用 /handanimations、Mod Menu，或在 選項 → 控制 → 按鍵綁定 中設定的按鍵開啟設定。

每個部分都有獨立開關：手持物品時顯示手臂、副手手臂、物品揮動、衝刺姿勢、拔出動畫、技能動畫、鑽頭抖動、使用動畫和待機小動作。滑桿可以調整晃動、檢視速度，以及手臂的位置和旋轉。

常見問題

如何在 Minecraft 第一人稱下看到自己的手握著物品？
原版 Minecraft 沒有這個選項：一拿起物品手臂就會消失。安裝 Hand Animations（Fabric，客戶端），手就會握住每件物品，並帶有揮動、使用、拔出和檢視動畫。
Minecraft 26.2 有 Hold My Items 的替代方案嗎？
有。Hand Animations 在 Minecraft 26.2 上做同樣的事：看得到的手握著你的物品，外加檢視按鍵，並且圍繞 Hypixel SkyBlock 物品設計。
能在 Hypixel SkyBlock 上使用嗎？
能，它就是為此打造的。它讀取每件物品的 SkyBlock 類型來選擇動畫，所以劍、鑽頭、法杖和釣竿各有各的動作。
我能自己做物品動畫嗎？
能。資源包中每件物品放一個 JSON 檔案，就能為任何物品設定專屬的握法、動畫和模型。格式說明和範例資源包都在 GitHub 上。
如何變更手持物品的大小或揮動速度？
安裝 NoForcedPacks。Hand Animations 會沿用它的手持物品大小和揮動速度。
需要在伺服器上安裝嗎？
不需要。Hand Animations 是純客戶端模組，只需你自己安裝。
使用 Hand Animations 會被封鎖嗎？
它只改變你自己螢幕上手的外觀，不提供任何遊戲優勢。但還是請查看伺服器規則：如何使用由你自己負責。

從 Hold My Items 轉過來？

Hold My Items 讓手在第一人稱下可見，但它的最新版本只支援 Minecraft 1.21.11。Hand Animations 把同樣的想法帶到 Minecraft 26.2，並加入 Hypixel SkyBlock 動畫、資源包定義的單一物品動畫，以及 NoForcedPacks 的物品大小和揮動速度。
